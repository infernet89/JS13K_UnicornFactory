Catch falling rings on your unicorn's horn — red, orange, yellow, green, blue, indigo, violet. All seven in order and the unicorn is finished: it sells itself and rides its own rainbow off the screen. Catch a wrong colour and the stack is ruined.

Spend the money on nine upgrades and up to six apprentice unicorns working the floor beside you. **130 sales finish the rainbow bridge.** About nine minutes for a full run, and it saves as you go.

### Controls

Every action has an on-screen button too, so it plays fine on a phone.

| Key | Action |
| --- | --- |
| Mouse / drag, arrow keys or `A` `D` | Move |
| `Space` | Sell now (finished unicorns sell themselves anyway) |
| `X` | Scrap a ruined stack |
| `C` | Cut off just the last ring (needs the Horn Saw) |
| `B` or `Esc` | Shop |

- **The soundtrack gains a layer every few upgrades**, so the factory sounds richer the more you have built. Headphones recommended for the ending.
- There is a cheat code in here. You already know it.
